An individual software engineering project done as part of my dissertation, this project is a learning tool for new users of the Linux command line; teaching them the essential commands and also getting them used to navigating the filesystem from the terminal. Includes research into gamification features and common UX patterns from existing solutions that are implemented and evaluated to see if they improve on the end product in terms of learning effectiveness, engagement, and enjoyment.
